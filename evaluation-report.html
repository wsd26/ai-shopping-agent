1. 系统架构设计

采用多Agent协作架构，4个专职Agent通过AgentBus事件总线通信。每个Agent职责单一、状态独立，避免单体架构的耦合问题。

3. 意图识别评测

意图识别是系统的入口能力。OrchestratorAgent内置意图分析引擎，通过正则匹配+中文产品名检测，将用户自然语言输入分类为6种意图类型。

3.1 6种意图类型定义

意图类型触发条件路由目标示例
greeting 问候语匹配 Advisor → 欢迎引导 "你好"、"hi小快"、"晚上好"
specific_product 提及已知商品名 Advisor → 商品详情问答 "和田大枣包邮吗"、"碎花连衣裙有S码吗"
current_product 指代当前展示商品 Advisor → 当前商品问答 "这个多少钱"、"这个什么材质"
product_search 品类搜索 Advisor → 商品搜索 "有没有男装"、"有裙子吗"
command 操作命令 Executor → 执行动作 "加入购物车"、"帮我盯着"
general 无匹配（兜底） Advisor → 通用回复 "今天天气不错"

3.2 意图识别优先级

关键设计：命令检测优先级最高，确保"加入购物车"不被误判为product_search或specific_product。

greeting → commands → named product → current_product → product search → general

3.4 评测中发现的Bug（4个）

Bug #1: "加入购物车"无法识别为命令
正则 /加购物车/ 要求"加"后紧跟"购物车"，但"加入购物车"中间有"入"字。
修复: 扩展正则为 /加入购物车|加到购物车|加购物车|加购/
Bug #2: 意图检测顺序错误
"买这个"被 detectProductMention 先匹配"这个"判为 current_product，实际应是 command。
修复: 将commands检查提前到named product和current_product之前
Bug #3: 问候语覆盖不全
缺少"嗨"、"哈喽"、"在不在"、"主播好"、"晚上好"、"上午好"等常见问候语。
修复: 扩展greeting正则到12种模式
Bug #4: 命令词覆盖不全
缺少"加购"、"加到购物车"、"帮我看一下"等命令变体。
修复: 扩展command正则到12种模式

4. 商品搜索评测

AdvisorAgent的searchProducts方法基于中文部分字匹配算法，支持品类筛选和多关键词联合搜索。

4.1 搜索算法

  • 关键词提取：将用户输入分词，提取2字及以上词组
  • 部分字匹配：按品类筛选后，逐商品名称/描述进行单字匹配
  • 多关键词OR逻辑：任一关键词命中即视为匹配
  • 品类筛选：category参数不为null时先过滤品类

4.2 评测结果

⚠ 部分字匹配的副作用
中文部分字匹配在跨品类搜索时会产生噪音匹配。例如搜索"男装"时，护肤品"10片装"会被单字"装"匹配命中。这是算法特性而非bug——实际使用时品类筛选会解决此问题。

5. 监控评分评测

MonitorAgent内置10项评分规则的商品评分引擎，用于直播间商品切换时的主动推荐决策。评分≥65分时触发主动推送。

5.1 评分规则清单

1预算匹配+15商品价格在用户预算范围内
2低于预算+5商品价格低于预算下限
3略超预算(≤30%)+5超出上限但不超过30%
4品类偏好+20商品品类匹配用户偏好
5肤色匹配+10服装/护肤品类且匹配用户肤色
6高评分(≥4.7)+8商品评分≥4.7
7高销量(>5000)+7销量>5000
8大折扣(≥50%off)+10折扣≥50%

场景评分是否推送评分明细

7.2 商业价值论证（面试论述要点）

GMV驱动

  • 消除决策犹豫 = 提升转化率：每次AI解答都是一次成交机会
  • 主动推荐：MonitorAgent在商品切换时自动推送高匹配商品（评分≥65），被动浏览变主动推荐
  • 语音加购：减少操作摩擦，用户说"加入购物车"即可完成

用户增长

  • 降低新人门槛：直播购物新手不敢提问 → AI 1v1私密解答
  • 语音无障碍：覆盖通勤/忙碌/打字不便的用户群体
  • 差异化竞争：多Agent协作的智能导购体验，区别于传统直播电商

数据飞轮

  • 交互越多 → 用户画像越精准 → 评分引擎越准确 → 转化越高 → 平台粘性越强
  • MonitorAgent的评分引擎可持续调优阈值和权重

竞争壁垒

  • 直播间上下文感知：理解当前商品、用户画像、对话历史
  • 平台深度集成：与快手直播、商品库、用户系统深度绑定
  • 第三方无法复制：需要完整的直播数据+用户画像+商品体系

7.3 技术亮点

  • 关注点分离：4个Agent各司其职，降低耦合，便于独立迭代
  • 事件驱动通信：AgentBus解耦Agent间依赖，新增Agent只需注册
  • 冲突仲裁：内置15秒冷却期，防止多Agent同时推送打扰用户
  • 可测试性：每个Agent可独立测试，核心方法public暴露用于单元测试
  • 中文友好：意图分析引擎原生支持中文自然语言，部分字匹配覆盖口语化搜索
